# healthcare-topics-bertopic


Пайплайн для тематического моделирования и анализа полуформализованных интервью (на примере интервью о практиках заботы о здоровье в российских семьях).  
Сочетает **BERTopic**, **UMAP**, **HDBSCAN** и **guided-модели** .

---

## Основные этапы (по шагам)

1. **Извлечение реплик информантов** из транскриптов (интервьюер исключается).
2. **Лемматизация** с сохранением отрицаний (библиотека `pymorphy3`).
3. **Векторизация** с помощью `paraphrase-multilingual-MiniLM-L12-v2`.
4. **Снижение размерности** через UMAP, **кластеризация** через HDBSCAN.
5. **Извлечение тем** через TF-IDF (CountVectorizer с n-gram диапазоном).
6. **Настройка гиперпараметров** (min_cluster_size, n_neighbors, min_df).
7. **Guided-модели** — добавление seed-тем эксперта.
8. **Валидация** и группировка тем с помощью DeepSeek (по промпту из статьи).
